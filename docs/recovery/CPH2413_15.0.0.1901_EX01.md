## Recovery paths supported by evidence

### Soft recovery

The exact full OTA package is locally available. If Android or stock recovery remains reachable, the exact stock package/images provide a same-build restoration source. OnePlus documents Local Install / rollback flows for OnePlus 10T IN/EU/GLO firmware generations, demonstrating the stock recovery/local-update mechanism exists on this product family.

### Hard-brick / EDL recovery

Multiple independent repair-firmware sources document Qualcomm 9008 EDL restoration for CPH2413/OnePlus 10T using OPlus/Oppo service tooling and an exact-model firmware package. Those sources also state that modern protected devices require OEM/service authorization or an authorized account for the EDL flash operation.

Official OnePlus India support provides service-center reservation plus pick-up/drop repair, and the official OnePlus Australia RMA flow accepts repair requests for inspection and return shipping. Neither public OEM page specifically commits to CPH2413 Qualcomm 9008/EDL software recovery. These are concrete escalation channels, not proof that this exact hard-recovery operation has been accepted or is available to the owner.

Therefore the evidence currently supports **an assisted/service recovery path**, not a verified self-service hard-recovery path.
