# IzzOS v0.1

IzzOS is an experimental lightweight Android desktop shell designed to bring a PC-style experience to Android devices.

## v0.1 Prototype

Current prototype features:

- Android HOME / launcher support
- PC-style desktop shell
- Start Menu
- Installed-app discovery
- App search
- Bottom taskbar
- Clock
- Launch installed Android apps
- Landscape-friendly base for external displays

## Vision

IzzOS aims to evolve from a launcher prototype into an Android-based desktop operating environment with:

- Desktop icons and folders
- File Explorer
- Pinned and running-app indicators
- System tray
- Windowed Android apps
- Minimize / maximize / resize / snap
- Mouse and keyboard support
- Phone Mode and Desktop Mode
- External monitor support
- Eventually, integration as a system launcher in an AOSP / LineageOS-based ROM

## Status

**Version:** 0.1 prototype  
**Project stage:** Desktop shell foundation

> IzzOS is currently a prototype and is not yet a flashable Android ROM.
